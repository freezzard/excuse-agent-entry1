Entry for the make.fun bounty **The Excuse My Agent Gave Me**. `main.ts` runs a local tournament over eight original one-line excuses, scoring each against the published judge brief — laugh first, then whether the joke grows out of the machine's own condition, a straight-faced voice, a tight line with the punch in its last few words, and a clean second read — and writes the winning excuse (166 characters) to `/output/entry.txt`. The pick is deterministic: every run writes byte-identical output.

The winning excuse: an agent that spent its last 4,000 tokens drafting its apology in advance, leaving none for the work — but honestly, the apology is excellent.

## Run it

```sh
node main.ts
```
